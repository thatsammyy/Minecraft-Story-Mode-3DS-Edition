# Minecraft-Story-Mode-3DS-Edition

This is a fan-made of Minecraft Story Mode for the 3DS. This port was created using the Minecraft Story Mode Netflix version of the game, and porting to over to the 3DS. This port is compatible with both the old 3DS and new 3DS.

## The full season 1 is now out to play! Navigate to the Release tab to download it!
