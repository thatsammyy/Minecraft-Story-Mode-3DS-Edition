# Minecraft-Story-Mode-3DS-Edition

This is a fan-made of Minecraft Story Mode for the 3DS. This port was created using the Minecraft Story Mode Netflix version of the game, and porting to over to the 3DS.

Currently, the Beta is out to play; more updates will be releasing soon.
